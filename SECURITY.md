# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub private vulnerability
reporting when it is enabled for this repository; otherwise contact the project owners through the
organization's approved private channel.

Include the affected version or commit, impact, reproduction steps, and any known mitigation. The
maintainers should acknowledge a complete report within five business days and coordinate a fix and
disclosure timeline according to severity.

Only the latest release line will receive security updates once releases begin.
